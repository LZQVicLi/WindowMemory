# 使用说明

## 场景

每套屏幕组合可以有多个场景。原有 1.0/1.1 布局会作为原组合的一个场景保留。

- 从选择器切换当前场景；切换本身不移动窗口。
- 点“新建”输入名称，新场景以当前保存记录为起点。
- 调整真实窗口后点“记住布局”更新当前场景。
- 点“恢复位置”移动已打开的匹配窗口；点“启动 App 并恢复”先打开场景中的 App。
- 更多菜单支持重命名、删除和单场景导出。删除不改变真实窗口位置。

## 可视化布局预设

在左侧一级导航“布局库”查看推荐，与“设置”平级；控制台的“布局库”按钮也能直接进入该页面。布局库默认选择“自动匹配当前屏幕”：读取当前连接数量、macOS 主屏标记、横竖方向、可用宽高，逐屏提供不同推荐。MacBook 主屏与外接竖屏会得到不同模板。

- 紧凑的多屏主屏优先双栏、专注，避免过多分区；单屏时也推荐工作区加侧边工具。
- 竖屏推荐纵向通讯 / 阅读 / 参考、长文阅读或上下分区；小竖屏减少分区数量。
- 21:9 超宽屏推荐三列或居中布局，32:9 优先四列与居中主工作区。
- 常规大横屏支持工作区、四格及通讯栏等组合。

在“浏览模板”中还能查看笔记本 16:10、常规横屏 16:9、竖屏 9:16 / 10:16、超宽屏 21:9、超宽带鱼屏 32:9、方屏 1:1、办公屏 4:3 / 3:2 等七类屏幕模板。库内共有 12 种分区形式；每类提供多个模板，而不是按显示器品牌限制。

自动推荐使用 macOS 的逻辑可用尺寸，并扣除菜单栏、Dock；分类中的分辨率仅作常见屏幕示例，Retina 缩放后的逻辑尺寸可能不同。浏览其他分类不会修改布局；选择模板后，可以在指定的实际屏幕上预览并配置 App。手动选择的模板会按该屏可用尺寸缩放，应用自身最小窗口尺寸仍可能限制效果。

点“为此屏配置”只需为这块屏幕选择 App，其他屏幕可全部留空。切换编辑器中的显示器会保留已配置内容，保存仍归属于当前屏幕组合。

点击区域中央的“选择应用”，搜索本机已安装 App，选择后显示图标与名称占位。可选“留空此区域”，不要求填满全部区域，但至少要选择一个 App 才能保存。切换屏幕会保留此前的选择；切换预设时保留同名主/辅助区域的选择，移除不再存在的区域。

输入场景名称并点击“保存为新场景”，会新增并选中这个场景，不覆盖已有场景。此时不打开 App 或移动窗口；后续使用“启动 App 并恢复”、恢复位置、自动恢复、启动编排、快捷键及导入导出，与其他场景完全相同。

预设窗口没有固定标题，按同一 App 的窗口顺序匹配。若同一 App 选了多个区域，需要这个 App 实际已存在足够的普通窗口；程序不创建文档、浏览器标签或额外窗口。应用自身最小尺寸也可能限制实际布局。预设不需要窗口控制权限即可编辑和保存；真正移动窗口仍需要权限。

## 我的模板

布局库下方的“我的模板”可点击“新建模板”，输入名称，选择参考屏幕并添加区域。用百分比填写左、上、宽、高，预览随编辑更新。区域宽高至少 5%，必须位于屏幕内，最多 32 个，允许重叠。自定义模板不必先指定 App，即可保存。

已保存的场景可通过控制台更多菜单“添加到布局库”，或布局库“从当前场景添加”，按每个有启用窗口的屏幕各生成一个模板，保留几何位置与 App 选择，不复制窗口标题匹配规则，也不改变原场景。单屏超过 32 个启用窗口时需要先减少数量，程序不会悄悄丢弃多余窗口。

每个模板可“使用”“编辑”或“删除”。使用前可选择目标屏幕，然后在区域中重新选择 App 或留空，最后保存为新场景。删除模板不会删除此前生成的场景。模板库最多 100 个，保存在本机 `layouts.json`，也参与写入前的上一版备份；常规场景导入导出不包含整个私人模板库。

## 快捷键和启动

“启动与快捷键”页面可选择修饰键与按键；组合重复或系统注册失败时提示，并保留原配置。无需窗口记忆处于前台，但它必须正在运行。

启动排序通过上、下箭头调整。“间隔”是处理完当前 App 后等待多久再打开下一个；“窗口”是尝试匹配归位的最长重试时间。两者独立。成功归位的窗口不会在后续重试中被持续拉回。

## 导入导出

设置页可导出全部场景，场景菜单可导出单个场景。导出包含窗口标题、App 标识、屏幕信息和每场景启动配置，不包含全局快捷键、外观或登录项目。

导入也支持旧版 `layouts.json`。文件大小最多 5 MB，单文件最多 100 场景，每场景最多 500 窗口。异常数值、重复标识和未知屏幕绑定会被拒绝。

屏幕组合与当前 Mac 不同则出现映射对话框，逐个选择目标屏幕；可以将多个原屏幕映射到同一新屏幕，或保留原屏幕绑定。导入以新的场景 ID 新增，并在名称后标记“导入”；不覆盖或自动启用已有场景。

## 外观、语言与分享

在设置中选择跟随系统、浅色或深色，切换立即生效；跟随系统也会响应 macOS 后续的外观变化。

语言可选跟随系统、简体中文、English、Français、Español、Русский 或 العربية。阿拉伯语使用从右到左布局。应用内语言立即生效并保存在本机；App 名称及 macOS 自己提供的文件选择器等系统控件可能仍使用系统语言。用户保存的场景名称、App 名称和窗口标题不翻译。

分享卡片可打开主流渠道的分享入口，发送前由你确认；不要求 App 访问你的社交账号。不支持网页直接分享的微信使用复制链接或系统分享。系统分享可用渠道取决于本机安装的扩展。分享不包含布局文件、App 清单或窗口标题。

## 窗口控制权限

点“开启权限”只打开一次系统设置，同时保留一个悬浮引导窗。将 App 图标拖进系统权限列表，或使用列表的“＋”添加，然后开启旁边的系统开关。**拖入只是添加 App 的便利方式，开关仍由 macOS 管理。**

App 在返回前台时立即检查，也每秒检查一次，并在授权或撤销时更新状态。未收到系统授权时不会把权限显示为已开启。

当前下载包采用本地临时签名，尚未 Apple 公证。更新后 macOS 可能保留旧版本的授权记录。如果开关开启但状态仍未授权，移除旧记录，重新拖入 `/Applications/窗口记忆.app` 并开启；必要时退出并重新打开 App。此操作不删除布局数据。

## 故障排查

- **已允许权限但仍显示未授权**：更新本地签名后，移除系统中的旧授权项，再添加 `/Applications/窗口记忆.app`。
- **部分窗口无法恢复**：检查最小尺寸、全屏、最小化、其他 Spaces，以及 App 是否允许辅助功能调整窗口。
- **同一 App 的窗口互换**：窗口标题相同或变化时会退回顺序匹配。
- **文件损坏**：程序会停止写入并保留原文件。先备份原文件，再检查 `layouts.previous.json`；不要直接删除唯一副本。
- **登录后没有启动场景 App**：该选项默认关闭，而且登录时必须存在与当时显示器组合匹配的场景。
